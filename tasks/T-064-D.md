# T-064-D Import a whole document as components and an assembly

- **Status:** open
- **Size:** L (split it again when claimed if the window and the saving are separate work)
- **Agent:** careful
- **Needs:** T-064-B, T-064-C
- **Needed by:** none
- **Touches:** `import_split_dialog.py` (new), `library.py` (also T-058-B), `component_editor/import_dialog.py`, `USER-GUIDE.txt`
- **Size gate:** yes

- [ ] The split review shows the pieces as a list (name, a preview, the warnings) with
      the cuts adjustable: change the heading level, merge with the next, split here,
      rename, tick to leave out, move up or down
- [ ] A name box for the assembly (default from the file name) and the page layout
      file (default: the imported file; the user may choose another; the file is never
      changed, and the usual layout check and its plain wording apply)
- [ ] **Save** creates every component (one version each, with its paragraph styles)
      and the assembly's first revision pinned to those versions **in one transaction**:
      if anything fails nothing is left behind (`library.create_components_and_assembly`,
      no schema change)
- [ ] A component name that already exists is shown and can be changed before saving;
      an identical component already in the library is offered as "use the existing one"
      instead of a duplicate
- [ ] The result opens in the saved-assemblies list (T-063) or Build an assembly
      with a plain summary of what was created
- [ ] Tests: a three-heading document becomes three components and one assembly whose
      composed text equals the original; failure rolls back; original file unchanged;
      guide text; hand check on Windows and in real Word (UT-001, UT-003)
