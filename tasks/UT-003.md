# UT-003 Windows checks of recent window changes

- **Status:** open
- **Size:** S
- **Agent:** human
- **Needs:** release 0.4.3 or later installed on Windows
- **Checks:** T-063, T-051-B, T-043-D, T-043-E, T-046-C, T-046-D, T-040, T-041, T-048-C, T-043-C, T-044, T-045, T-046-B, T-048-A, T-060-B, T-061, PR #70 (assembly buttons)

Each item is a hand check that code and tests cannot make: the Linux checks
use a virtual display and cannot see Windows title bars, fonts or focus. This
check does not block any coding task. Use invented wording only (the
repository is public). A fault becomes a T- task, with a screenshot.

- [ ] **Maximize and restore (T-040):** the Components and Build an assembly
      windows have a maximize button; maximize, restore and minimize work;
      choosing Manage components again brings the window to the front
- [ ] **Toolbar at several widths (T-041):** every button is reachable at the minimum and a maximized width, and the rows wrap rather than cut off
- [ ] **Formatting buttons (T-045):** press Bold, Italic, Heading, Bullets and Numbering twice each; each undoes its own effect in the formatted and raw-text views
- [ ] **Publisher fill (T-046-B):** the From publisher control fills one field; Fill all from publisher reports what was filled and what had no matching field
- [ ] **Saving is obvious (T-044):** after Save version you cannot miss that it
      saved (the green message, the Version column, no "Unsaved changes" mark)
- [ ] **Field picker (T-043-C):** the Field button opens a searchable, grouped list;
      New field... makes a text, a choice and a date field; Edit and Archive work
- [ ] **Recent list (T-048-C):** the Recent list shows under the three choices; a moved file says "file not found"; Remove from list takes it off; one click reopens a Word file or an assembly
- [ ] **Start screen (T-048-A):** the first screen shows Existing contract
      assembly, New contract assembly and Word file; Alt+E, Alt+N, Alt+W work; the
      buttons fit on a small window
- [ ] **Assembly window buttons (PR #70):** Save assembly, Open saved and Close
      are visible even with a long page-layout message, and the Assembly name
      box is there
- [ ] **Page layout file (T-060-B):** a file that only lacks styles is accepted
      with one calm line and no question; a file with no page size asks Use this
      file or Choose another
- [ ] **Paragraph style (T-061):** the Style button changes a paragraph; Title is
      centered in the preview; saving a style change makes a new version
- [ ] **Publisher details (T-046-C):** in Publisher Profiles, "Add a detail…" makes
      Publisher type with three choices; each profile has a drop-down; choosing a
      publisher fills {{Publisher Type}} and the matching wording appears
- [ ] **Parties (T-046-D):** Publishers > Parties in a contract; an assembly with
      "Publisher One’s Address" and "Publisher Two’s Address" shows two publisher
      choices, and each fills only its own fields
- [ ] **Starter fields and help text (T-043-D, T-043-E):** the picker's "Add starter
      fields…" works; a field with a description shows it under the field in both forms
- [ ] **Copy and paste (T-051-B):** select some wording that has bold text next to
      brackets and copy it into Word and into an email: it reads as shown, with no
      backslashes or stars; paste text containing `**` and `(`: it stays readable;
      bold a word next to a bracket and no backslash appears; right-click shows
      Cut, Copy, Paste and "Copy as stored text"
- [ ] **Saved-assemblies list (T-063):** Existing contract assembly shows a preview
      beside the highlighted assembly; moving the highlight redraws it; a Title
      paragraph is centered; "Earlier revisions…" previews an older one; the window
      maximizes and the preview pane grows
- [ ] Anything awkward, in plain words
