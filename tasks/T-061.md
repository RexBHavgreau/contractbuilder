# T-061 Choose a paragraph style in the component editor (Title, Subtitle, Body Text...)

- **Status:** open: needs Beaux's decision on how the choice is stored
- **Size:** L (split into subtasks after the decision)
- **Agent:** careful
- **Needs:** Beaux (storage choice below), T-060-A (the styles must exist in the output), T-042 (decide together with centering; both are "how a paragraph is formatted")
- **Touches:** `md_to_word.py`, `docx_compose.py`, `docx_to_markdown.py`, `component_preview.py`, `component_editor/toolbar.py`, `component_editor/text_rules.py`
- **Size gate:** yes

Beaux (2026-11-21), after the first contract was built from components: the
title came out as an ordinary paragraph because the editor has no way to say
"this is the title". Headings (`#`) already map to Heading 1 to 3; Title,
Subtitle, Body Text and similar do not. He wants the style chosen **in the
component editor**, applied **when the document is created**, so the output
looks right without anyone repairing it in Word afterwards.

Today every non-heading, non-list paragraph is written in Normal, and the
three-level headings are the only style the wording can request
(`md_to_word.py`). The layout file may define more (a file Beaux uses has
Title, Subtitle, Body Text, Body List, Block Text and Table Signature).

**Decision for Beaux (the storage; users never see it):** the editor keeps
component wording as Markdown and Beaux prefers no new syntax. Options:

1. **A style per paragraph kept beside the Markdown** (a small list in the
   component's stored data: paragraph number and style). Nothing new in the
   text; editing the text can shift paragraph numbers, so the editor must keep
   them in step
2. **A whole-component style**, "this component is a Title": simplest, covers the
   title, subtitle and signature blocks, and does not cover a single odd
   paragraph inside a clause
3. **A marker the editor writes and hides** (for example a first line such as
   `::: Title`). Most flexible, but it is new syntax inside the wording

Recommendation: start with option 2 for whole components (title, subtitle,
signature block), then add option 1 only if single paragraphs need it.

- [ ] Decision recorded in `decisions/`
- [ ] The editor has a **Paragraph style** drop-down listing plain names (Normal,

- [ ] At document creation the chosen style is used if the layout file has it,
