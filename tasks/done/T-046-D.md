# T-046-D More than one publisher in a contract (parties)

- **Status:** done (2026-11-21, PR pending)
- **Size:** M
- **Agent:** careful
- **Needs:** T-046-A, T-046-B
- **Touches:** `simple_app.py`, `assembly_builder.py`, `publisher_profiles.py`
- **Size gate:** yes

Beaux's sample component has two parties with fields named for their role:
`{{ Publisher One (Proprietor) }}`, `{{ Publisher One’s Address }}`,
`{{ Publisher One’s State }}`, `{{ Publisher Two (Publisher) }}`,
`{{ Publisher Two’s Address }}`, `{{ Publisher Two’s Contact }}`. Today the
forms have one "Saved publisher" box, and the profile matching knows only a
single set of names ("Publisher Name", "Contact Email"...). So none of these
fields would fill from a profile, and a second party could not come from one.

- [x] Define **parties** (a name such as "Publisher One", with an optional role
      label) in the field definitions or the field-matching window (T-046-A):
      a field is "the address of Publisher One", so every profile column
      (name, address, state, contact...) is available for each party without
      listing every combined name by hand; a name like `Publisher One’s
      Address` matches automatically
- [x] The template form and the assembly form show **one publisher choice per
      party that appears in the document**, with the per-field and fill-all
      controls of T-046-B working per party
- [x] A document with one publisher behaves as now; the old names keep working
- [x] Tests: two parties filled from two profiles, one party left to type, and
      curly and straight apostrophes in the names; hand check on Windows

Note 2026-11-21: schema v7 also adds `publisher_parties`. **Publishers > Parties in a contract** defines parties (name, optional role). `publisher_parties.py` matches a field named for a party plus a detail ("Publisher One’s Address", with either apostrophe, any capitals) without listing combined names, `publisher_panel.py` (shared by the template form and the assembly form) shows one publisher choice per party that appears, with per-party Fill all and per-field From publisher. A document with one publisher behaves as before. Party changes apply the next time a template or assembly is opened. Hand check on Windows: UT-003.
