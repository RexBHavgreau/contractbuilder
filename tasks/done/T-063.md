Beaux (2026-11-21): the **Existing contract assembly** button does not need the
Build an assembly window, only a list of assemblies. A **preview pane beside the
highlighted assembly** would show what he opens the builder for today: what
the contract says. Since T-048-B the button already opens a list
(`open_saved_assembly_direct` in `assembly_open_dialog.py`: name, latest
revision, date, newer-wording mark, search) and goes to the fields; what is
missing is the preview.

The component manager already previews wording (`render_markdown_preview` with
the preview tags in `component_editor/styling.py`), and the builder previews a
whole assembly (`assembly_helpers.preview_segments_for_components`, with each
component's version label and its paragraph styles from T-061). Reuse both:
there should be no second preview renderer.

- [x] The list window becomes its own module (`assembly_picker_window.py`: a new
