# UT-001 Check generated documents in real Word

- **Status:** open
- **Size:** S
- **Agent:** human
- **Needs:** a document built from components (any recent release)
- **Checks:** T-019-F, T-033, T-060-A, T-061

Package-level tests cannot prove Word will open a file and show it correctly.
This check does not block any coding task; if it finds a fault, open a T- task
for it with the file attached.

- [ ] Open a document built from an assembly in Word on Windows (and on macOS if
      possible): no repair message, headings and tables right, clause numbers
      continue 1, 2, 3 across components, headers and footers present
- [ ] Build one from a page layout file that has **no** Title, Subtitle or List
      Number style (T-060-A, T-061): the title is centered, bullets and numbers
      look right, and a Title chosen in the editor appears as a Title
- [ ] Record findings here, one line each
- [ ] Repeat after T-031 (links) if it is built
