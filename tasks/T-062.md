Beaux (2026-11-21): the fill-in window asks separately for, for example, the
number of copies "(Spelled Out)" and "(Digit)", and for the number of years.
The engine already handles this, so no code change is wanted, only clearer
instructions.

**What the engine does today** (checked 2026-11-21): one field can appear in
several formats and is asked for **once**:

    {{Copies | number}}          7
    {{Copies | number-words}}    seven (7)

`number-words` writes the usual contract form, words with the digits in
brackets. It does **not** write words alone ("seven"). The wording that was
written as two fields can be rewritten as one field with the right format.

- [ ] USER-GUIDE.txt: a section **Asking once for a number** with the two
      formats above, a before and after (two fields, "(Spelled Out)" and
      "(Digit)", become one field in two formats), and how to edit a component
      to do it: open it, replace the two placeholders by one, save; assemblies
      keep the old version until Review updates
- [ ] The guide says plainly what is not available: words **without** the digits
      (see the follow-up below), and that a saved assembly's old fields stay
      until it is updated
- [ ] The Help menu points at the section

**Follow-ups, only if the guide is not enough (do not start them unasked):**
a `number-spelled` format that writes words only ("seven") in `core.py`; a
**Show as** choice in the field picker; a **Combine fields…** tool that rewrites
components that already use a pair of fields (it would save new versions only).
