Beaux (2026-11-21): **Import Word** takes the entire document into one
component. He wants two other ways:

1. **Only part of it.** Choose a paragraph, or several, and import just those as
   one component.
2. **All of it, as discrete components saved together as an assembly.** An
   existing contract becomes a set of components, each reusable on its own, plus
   an assembly that puts them back in order.

Today `import_docx` returns one Markdown draft and a list of warnings, and the
review window (`component_editor/import_dialog.py`) saves one component. The
reader already keeps each paragraph's Word style (T-061) and knows headings,
lists and tables, so a document can be cut into pieces at those boundaries.

**Defaults to build, for Beaux to correct on first use** (no decision needed
before starting): cut a document at **Heading 1** (or Heading 2 if there is no
Heading 1); a document with no headings is offered as one component and the
user can place cuts by hand; each piece is named from its heading (or the first
words) and the name is editable; the assembly takes the imported file's own page
layout as its page layout file (it is never changed) and its name from the file
name, both editable; pieces with nothing in them (an empty heading) can be left
out with a tick.
