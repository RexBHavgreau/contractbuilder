# T-058-B Calculate editable starting values for fields

- **Status:** waiting (T-058-A and T-046-A)
- **Size:** M
- **Agent:** careful
- **Needs:** T-058-A, T-046-A
- **Needed by:** none
- **Touches:** `library.py` (one schema migration) (also T-064-D), `field_defaults.py` (new), `ui_widgets.py`, `assembly_document_window.py`, `simple_app.py`
- **Size gate:** yes (small pure-Python module; no new third-party dependency)

A field may have a starting value calculated from another field, but the
person filling in the form must always be able to see and change that value.
The migration must follow T-046-A's schema migration in merge order; do not
start this task before both dependencies are merged.

- [ ] A field definition can carry one starting-value rule, selected from
      plain choices rather than a typed formula: a number of days, weeks,
      months or years before or after another date field; the same as another
      field; or today's date.
- [ ] The new migration adds the rule to field definitions transactionally,
      makes the usual verified backup, and preserves the existing rule that
      an older app must not downgrade the database.
- [ ] `field_defaults.py` contains pure functions for evaluating rules.
      Tests cover month ends (31 January plus one month), leap years, blank or
      unreadable source dates (no value and a plain note), and rules that point
      to themselves or form a loop.
- [ ] The fill-in form updates the calculated value when its source field is
      entered or changed, until the user edits the calculated field by hand.
      After a manual edit it leaves the value alone; a small **Recalculate**
      control reapplies the rule. The result uses the same date format as the
      source date.
- [ ] The value is visible and editable before document creation; no rule
      writes hidden or irreversible content.
- [ ] Hand check on Windows.

**Done when:** entering an effective date calculates the signing deadline,
the user can change it, and the completed document uses the changed value.
