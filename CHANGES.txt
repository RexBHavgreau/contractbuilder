# What's new

## 0.4.3

The main window now opens with three clear ways to start: Existing contract assembly, New contract assembly, or Word file. Press Alt and E, N or W as a shortcut.

Fixes in the Build an assembly window: the Save assembly button and the others no longer disappear when a long warning is shown (the warning now wraps), and the Assembly name box is no longer hidden in a short window. The Word "shell" is now called the page layout file, with a line explaining what it is.

Alternative wording written inside a sentence no longer leaves a doubled space or a stray space before a comma or full stop when a phrase is left out.

## 0.4.2

Choose contract fields from a searchable, grouped picker instead of retyping names. Create reusable text, long-text, date, money, number, list and choice fields, or guided optional and conditional wording and singular/plural wording. Keep the picker open to insert several fields in a row, and edit or archive fields you have created.

Publisher profiles can now be matched to the field names used in your own contracts. Add custom matches from the Publishers menu; your matches take priority over the built-in names.

## 0.4.1

Fixes the error message that could appear when the app restarted itself after an automatic update ("Failed to load Python DLL"). The update itself always worked.

If you are updating from 0.4.0 you may see that message one more time, because the old version starts the new one. Click OK, then open Word Template Filler again from its icon. Updates after that should restart cleanly.

## 0.4.0

New Components menu. Write reusable contract wording once, with buttons for bold, italic, headings, lists, numbered clauses, tables and fields, and a preview as you type. Import wording from an existing Word file and check it before saving. Every saved change is kept as a new version.

New Build assembly window. Choose a Word shell for the page layout, pick components, put them in order, leave optional ones out, and see the whole contract before you create it. Fill each field once, load a publisher profile if you like, and save a new Word document. Clause numbers continue from one component to the next.

Save an assembly to build the same contract again later. If a component's wording changes, nothing happens to your saved assembly until you review the changes and choose to update.

Word templates work exactly as before. Components and assemblies stay on this computer.

## 0.3.1

Automatic update checks now run no more than once every 24 hours. You can still check for updates whenever you like from the Help menu.

When GitHub temporarily limits update checks, the app explains that it will try again later. Automatic checks stay quiet.

When an update is available, the prompt includes a short list of what changed.

## 0.3.0

Choose a Word template, fill in its fields, and save a completed copy without changing the original.

Save publisher details once and load them into matching fields in later contracts.

Check for updates from Help. On Windows, the app can download and install a newer release for you.
