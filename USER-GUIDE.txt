WORD TEMPLATE FILLER
USER INSTRUCTIONS

WHAT THIS DOES

Word Template Filler reads a Word document containing placeholders, asks you
to fill in those placeholders, and saves a completed copy as a new .docx file.
The original template is never changed.

1. CHOOSE A TEMPLATE

Click Browse and select a Word .docx or .dotx file.

The application scans the document and finds each unique placeholder. A
placeholder is a field name enclosed in double curly braces, for example:

    {{Recipient Name}}

2. FILL IN THE FIELDS

The application creates one input for each unique field, in the order the
fields first appear in the document.

Type the information requested. If the same placeholder appears several
times, you only need to fill it in once; every occurrence will receive the
same value.

A placeholder can appear in the main text, tables, headers, footers,
footnotes, or endnotes. The application fills in all of these locations.

Some templates may use specialized fields, such as dates, amounts, lists, or
choices. The application applies the formatting specified by the template.
For ordinary text fields, your entry is inserted as you type it.

3. CREATE THE DOCUMENT

Click Create document and choose where to save the completed file.

The application checks formatted entries before creating the document. If a
field is empty, it tells you and asks whether to continue. Empty fields are
represented by a blank line so they can be completed later in Word.

The completed document is saved separately. The template remains unchanged.

HIGHLIGHTING

Select Highlight inserted text for review to mark the wording inserted by the
application in yellow. This can help you review the completed document. It
does not change the template.

WRITING A SIMPLE TEMPLATE

Open a new or existing Word document and type the wording that should remain
the same. Wherever something needs to change, insert a field name between
double curly braces:

    Prepared for {{Recipient Name}}.

    Dear {{Recipient Name}},

    Your appointment is scheduled for {{Appointment Date}}.

    Please contact {{Contact Person}} with any questions.

Use the same field name wherever the same information should appear. The
application ignores differences in capitalization and extra spaces when it
matches field names, so {{recipient name}} and {{Recipient Name}} are treated
as the same field.

Format the placeholder in Word as you want the inserted wording to appear.
The inserted text takes its formatting from the field name inside the braces.
For example, make the field name bold if the completed name should be bold.

Save the Word document and select it in Word Template Filler.

TEMPLATE CHECKS

The application detects common placeholder mistakes, including missing
braces and invalid template syntax. Correct reported problems in Word and
select the template again.

A note about tracked changes, comments, highlighting, or other unusual Word
formatting does not necessarily mean the template is invalid. Review such
notes before relying on the completed document.

UPDATES

Word Template Filler checks for a newer published GitHub release when it
starts. You can also choose Help > Check for updates.

If an update is available, choose to open the release page and download the
version for your operating system. Close the application before replacing
the installed copy.

This repository is private. To let the application check its releases, set
the CONTRACTBUILDER_GITHUB_TOKEN environment variable to a GitHub fine-grained
personal access token that has read-only Contents permission for this
repository. Do not put a token in a template, script, or shared file. If the
repository is made public, no token is needed.

PRIVACY

Templates, answers, and completed documents are processed locally on your
computer. The application contacts GitHub only to check the latest published
release. It does not upload your Word documents.
