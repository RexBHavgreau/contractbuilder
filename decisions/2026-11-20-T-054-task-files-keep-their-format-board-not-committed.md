- **2026-11-20 — Task files keep the existing bullet format, and the board is generated, not committed.** Each task file starts with `# T-NNN title` and the same `- **Status:**`, `Size`, `Agent`, `Needs`, `Touches`, `Size gate` bullets the tasks always had, so nothing was rewritten and the split is provable line by line; `scripts/board.py` reads those bullets. A finished task moves to `tasks/done/` and the tests enforce it. The board is published by a workflow after each merge (run summary, artifact) and committed as `BOARD.md` only when the repository variable `BOARD_BOT_COMMIT` is `true`, because letting the Actions bot push to `main` is Beaux's call (T-057). Why: a committed generated board would be regenerated by every pull request and conflict again. Consequences: until the variable is set there is no `BOARD.md` in the repository; read the board with `python scripts/board.py`, in the latest `Task board` run on GitHub, or from its artifact.
